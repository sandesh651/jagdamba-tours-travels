# Jagdamba Tours & Travels

Responsive Konkan-to-Goa travel website built with plain HTML, CSS and JavaScript. Open index.html with the assets/ directory beside it. No build step is required.

Live website: https://jagdamba-konkan-escapes.sandesh-sd70.chatgpt.site

Includes 11 proposed regional circuits, automatic experience and lifestyle sliders, 3–4 captioned destination photographs per circuit, and a mobile-friendly destination selector. Malvan, Tarkarli & Devbag appears first.

Packages, services and ₹5,999 starting prices require business confirmation. The enquiry form prepares text locally; it does not send or store enquiries. No booking or payment backend is configured.

Photography credits and destination notes are included on the website. Image source dimensions vary. Google Fonts requires internet access.

Hosting is separate: GitHub commits do not automatically update the live site.
