# Jagdamba Tours & Travels

Konkan travel website using plain HTML, CSS and JavaScript. Open index.html with assets/ beside it. No build step required.

Live website: https://jagdamba-konkan-escapes.sandesh-sd70.chatgpt.site

Packages, services and INR 5,999 pricing require business confirmation. The enquiry form only prepares text locally; no backend or payments. Photos are illustrative Unsplash imagery. Google Fonts needs internet access.

Hosting is separate: GitHub commits do not automatically update the live site.
